# HR-018 Leave Web App — Print Exact Template

เว็บแอปใบลา HR-018 สำหรับกรอกข้อมูล บันทึกรายการ และพิมพ์แบบฟอร์มใบลา

## จุดสำคัญของเวอร์ชันนี้

- หน้า `แบบฟอร์มพิมพ์` ใช้ภาพพื้นหลังจากไฟล์ PDF แนบ `HR-018 ใบลา 20-06-67.pdf`
- ขนาดพิมพ์เป็น A4 portrait 210mm x 297mm
- ตั้งค่า `@page` เป็น margin 0 เพื่อให้ตำแหน่งตรงกับแบบฟอร์มมากที่สุด
- ช่องข้อมูลที่กรอกจากระบบถูก overlay ลงบนตำแหน่งเดิมของฟอร์ม
- checkbox ใช้เครื่องหมายถูกวางบนช่องเดิม ไม่วาดกรอบซ้ำ

## วิธีใช้งาน

1. เปิด `index.html` ด้วย Browser
2. กรอกข้อมูลใบลา
3. กด `บันทึกใบลา`
4. ไปที่เมนู `แบบฟอร์มพิมพ์`
5. กด `พิมพ์ / Save PDF`

## ตั้งค่าการพิมพ์ที่แนะนำ

เพื่อให้เหมือนต้นฉบับมากที่สุด ให้ตั้งค่าก่อนพิมพ์ดังนี้:

- Paper: A4
- Scale: 100%
- Margins: None / ไม่มีขอบ
- Background graphics: เปิด
- Headers and footers: ปิด

> หมายเหตุ: ความตรง 100% ยังขึ้นกับ Browser, Printer driver และการตั้งค่า scale/margin ของเครื่องพิมพ์ หากต้องการตรงแบบโรงพิมพ์ ให้ใช้ Chrome/Edge และตั้ง Scale 100%, Margins None เสมอ
